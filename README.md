# 🌌 AETHERIS AI
**Hyper-Intelligence Engine v1.0**

Aetheris is an advanced AI agent featuring:
- **Deep Search:** Live web integration.
- **Self-Correction:** 4x logic verification loop.
- **Multimedia:** Image and Video generation triggers.
- **Futuristic UI:** Glassmorphism and Voice-to-Speech.

### Setup
1. Create a `.env` file with your `OPENAI_API_KEY` and `TAVILY_API_KEY`.
2. Run `python aetheris_backend.py`.
3. Open `index.html`.
